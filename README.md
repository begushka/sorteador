# 🎲 Sorteador de Tópicos

Um pequeno projeto desenvolvido em Python utilizando Flask, HTML e CSS.

## 🚀 Funcionalidades

- Sorteio aleatório de tópicos.
- Distribuição entre três participantes.
- Limite de três tentativas.
- Mensagem de erro ao atingir o limite.

## 🛠️ Tecnologias utilizadas

- Python
- Flask
- HTML
- CSS

## 💻 Como executar

1. Clone o repositório.
2. Instale as dependências:

```bash
pip install -r requirements.txt
```

3. Execute o projeto:

```bash
python app.py
```

4. Acesse http://127.0.0.1:5000 no navegador.

## 📚 Objetivo

Projeto desenvolvido para praticar Python, Flask e integração entre backend e frontend.
